Moduli Integrati

Analisi tecnica delle modifiche applicate al sistema operativo.

🛡️

Privacy & Telemetria

Modifica le policy di registro (`HKLM:\SOFTWARE\Policies`) per disattivare l'invio in background di pacchetti diagnostici ai server Microsoft e disabilita l'assistente Cortana a livello di sistema.

🚀

Registry Tweaks

Disabilita l'Avvio Rapido (che spesso causa leak di RAM) e l'Ibernazione (liberando istantaneamente fino a 10GB di spazio su disco). Ottimizza il rendering UI per favorire gli FPS in gioco.

🔥

Debloat Engine

Utilizza comandi nativi Remove-AppxPackage per estirpare dal profondo le app preinstallate sponsorizzate (Bloatware) che consumano risorse in background.

📦

WinGet Orchestrator

Si interfaccia con il repository ufficiale Microsoft (Windows Package Manager) per scaricare gli eseguibili originali, bypassando i siti web infetti da malware.

Domande Frequenti

Tutto ciò che devi sapere prima di operare sul tuo sistema.

Come faccio a sapere che non è un virus?
System Suite è Open Source. Copiando il link del comando e incollandolo in un browser, puoi leggere il codice sorgente (scritto in PowerShell e XAML) in chiaro. Non ci sono eseguibili binari nascosti.
Posso annullare le modifiche (Tweaks)?
Le ottimizzazioni grafiche e le disattivazioni (come Ibernazione o Telemetria) possono essere riattivate manualmente da Windows o modificando le chiavi di registro corrispondenti.
L'installazione software è silenziosa?
Sì. System Suite usa i flag --silent --accept-package-agreements. Una volta premuto "Installa", puoi lasciare il PC a lavorare: installerà tutto in background senza chiederti mai "Avanti".
Il "Reset Windows Update" cancella i miei dati?
Assolutamente no. Si limita a riavviare i servizi crittografici di base (wuauserv, bits) e a rinominare la cartella della cache di download temporanea degli aggiornamenti (SoftwareDistribution) per sbloccare i download interrotti.
