Documentazione Moduli

Come funziona l'infrastruttura sotto il cofano.

Gestore Pacchetti (WinGet)

System Suite non ospita file eseguibili. Il software agisce come interfaccia grafica (GUI) per il Windows Package Manager (WinGet) nativo di Microsoft. Quando selezioni un'app, lo script invia una query ai server Microsoft e scarica l'installer originale, garantendo che i software siano sicuri e privi di malware.

Ottimizzazione Rete (DNS)

Il modulo di rete analizza l'adattatore di rete attualmente in uso (Wi-Fi o Ethernet) e sostituisce i DNS predefiniti del tuo operatore con quelli di Cloudflare (1.1.1.1). Questo riduce la latenza (ping) e impedisce ai provider di tracciare i siti web che visiti.

Motore di Debloat

Il comando di Debloat sfrutta i cmdlet Get-AppxPackage e Remove-AppxPackage per forzare la disinstallazione di applicazioni Universal Windows Platform (UWP) nascoste o protette, come Xbox Game Bar, 3D Builder e app promozionali.
