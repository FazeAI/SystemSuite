Percorso di Installazione

Bastano 30 secondi per iniziare a ottimizzare il tuo sistema.

1

Apri PowerShell

Cerca "PowerShell" nel menu Start, clicca col tasto destro e seleziona Esegui come Amministratore.

2

Esegui il Comando

Incolla il comando qui sotto nel terminale e premi Invio.

irm https://raw.githubusercontent.com/FazeAi/SystemSuite/main/WinUtility.ps1 | iex

(Clicca sul codice per copiarlo negli appunti)

Funzionalità

Automazione Intelligente

System Suite utilizza WinGet per installare software, rimuovere bloatware e ottimizzare le prestazioni di Windows in modo sicuro.

  • Disabilitazione Telemetria
  • Pulizia file temporanei
  • Installazione software in batch

Sicurezza

Il codice è 100% open-source. Puoi verificare ogni riga del file WinUtility.ps1 direttamente su GitHub prima di eseguirlo. Nessun file eseguibile binario nascosto.
