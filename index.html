Cloud Execution

Ottimizza e configura il tuo PC in un attimo, senza scaricare eseguibili.

1

Apri il Terminale

Cerca PowerShell nel menu Start di Windows, fai clic destro e scegli "Esegui come Amministratore".

2

Lancia la Suite

Clicca sul blocco di codice nero qui sotto per copiarlo. Poi vai su PowerShell, incolla (CTRL+V) e premi Invio.

Cosa c'è all'interno

Tutto ciò che ti serve, gestito dal motore nativo WinGet.

📦 Installazione Batch

Seleziona decine di software ufficiali (Chrome, Discord, VS Code, ecc.) e installali in un solo click. Nessun fastidioso popup "Avanti, Avanti, Fine".

🚀 Deep System Tweaks

Spegni la telemetria invasiva di Windows, rimuovi l'ibernazione per liberare spazio e forza il tema scuro in tutto il sistema operativo.

🧹 Fix & Riparazioni

Il PC è lento o non si aggiorna? Strumenti integrati per resettare Windows Update, ricostruire i DNS e riparare file di sistema corrotti (SFC/DISM).

Trasparenza Totale

Il codice è tuo alleato, non il tuo nemico.

Questo progetto è fieramente Open Source. Quando esegui il comando PowerShell, non stai avviando un file .exe oscuro, ma stai leggendo uno script testuale direttamente dal repository GitHub.

Puoi ispezionare ogni singola riga di codice prima di eseguirlo per la massima tranquillità.
